# Replay fixture: Node.js + real Drizzle ORM

A small order service on Node.js, `drizzle-orm` 0.45.4 and `pg` 8.23.1
(pinned in `package-lock.json`) with four flows: a vulnerable dual write
(A, MW1001), a transaction (B), an external effect inside a transaction
(C, MW1003) and a transactional outbox with a relay (D; the relay's own
window is MW1002). First-party test code; nothing here is an external
application.

```bash
npm ci && npm run build                           # once (replay never installs or compiles)
midwrite replay .                               # the plan
midwrite replay . --allow-execution             # control run + 16 cases
```

* `src/` is the application (analyzed, uninstrumented); `replay/harness.ts`
  wires the instrumented `pg` pool and the event-log transport into its two
  seams and runs the scenarios.
* `generated-harness/` was generated by `midwrite init-replay` for the
  MW1001 finding and completed by hand (see
  `docs/phase4/HARNESS-GENERATION.md`).

Results and caveats: `docs/phase4/NODE-DRIZZLE.md`.
